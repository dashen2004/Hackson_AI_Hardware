# 项目文档

此目录统一存放 AI＋硬件黑客松项目的创意、赛题、开发文档和硬件资料。候选产品方向见[项目创意池](创意/项目创意池.md)，当前具体产品方案与技术选型待确认。

## 建议阅读顺序

初次接触嵌入式开发的成员，建议先读[嵌入式开发术语对照表](开发/嵌入式开发术语对照表.md)，用熟悉的软件开发概念理解 SDK、固件、烧录、接线、通信和调试术语，再按下面的流程阅读。

1. 先读[赛题说明](赛题/AI硬件赛题说明.md)，明确参赛要求、交付物和项目边界。
2. 使用开发板时，按[开发板使用文档](硬件/开发板/灵机XJWB03标准开发板使用文档.md)完成硬件准备、环境配置、编译烧录、配网绑定与功能验证；硬件接口、插件开关和平台入口可从该文档的章节导航定位。
3. 接入外设时，先核对对应模块的型号、供电、接口与接线方向，再查芯片电气参数和寄存器；摄像头应结合模组参数、转接板网络定义与实物核对。
4. 实现或调整功能前，确认文档中的“待确认”项，并记录实际接线、SDK 配置和验证结果。

## 资料来源与验证范围

- 资料来自用户提供的硬件手册、原理图、模组图纸、示例压缩包、接线说明、实物照片、AI＋硬件赛题要求，以及灵机一动官方语雀使用说明；在线资料在对应文档中记录来源链接与整理日期。
- 每份 PDF 均已转换为同名 Markdown，PDF 原件不在 `docs/` 中保留；文档中的来源文件名仅作溯源记录。开发板原文件名中的下载重复后缀 ` (1)` 已去除。
- 正文按操作流程、硬件型号或技术主题组织，英文芯片手册保留技术术语与章节编号，并提供主题导航。纯文字、代码和表格均直接转为 Markdown；寄存器位字段逐位展开，参数表按项目拆行。按用户要求，现有文档的图片引用及配套图片已全部移除；未转录为文字的图形细节不在文档中提供。
- ZIP 原件保留，解压内容位于 `硬件/WS2812灯圈/参考例程/`；示例与链接文件按原始内容保存，未执行其中代码。
- 当前资料已进行文档整理和本地引用检查；电脑端工具链安装与编译验证见[Windows 工具链安装记录](开发/Windows工具链安装记录.md)。开发板已完成首次六镜像烧录与音频接线纠正，手机配网后实测普通复位自动联网、云连接及语音回答成功；连续追问的上下文承接、配网后断电冷启动及外设功能仍待验证，详见[开发板首次运行核对记录](开发/开发板首次运行核对记录.md)。
- 赛题正文写作 `LJWB03`，开发板手册写作 `XJWB03-DevKIT-V1`；两者命名对应关系及实际套件型号待确认。赛题的设备附页未提供完整内容，不能以收到的资料替代已确认设备清单。

## 组织约定

- 创意讨论放在 `创意/`，赛题要求放在 `赛题/`，硬件资料放在 `硬件/<模块>/`；后续按用途新增需求、开发、调试、演示等目录。
- 当前文档采用纯文字、表格和代码整理，不再保留或补回本次移除的图片。PDF 转换后的文字、表格、代码及可直接排版的公式写入 Markdown；无法用现有文字确认的接线方向、布局或图形细节标明“待确认”。
- 文档标题和正文按主题组织，不使用 PDF 页码作为章节；连续段落、同一张参数表和同一段代码应保持完整。长文档提供主题目录和可跳转的章节链接。
- 文件名应简短且能说明内容，文档内使用相对链接引用其他项目文件。
- 对尚未确定的内容标明“待确认”，已确认的决策及时更新到相关文档中。
