## ✅ 当前验证范围与资料冲突

- **2026-10-30** 已接通摄像头到板端姿态模型，USB 重插后恢复 COM7 通信、备份原应用并成功烧录。修正 S3 摄像头接收分块／缓存及结果日志格式后，45 秒实测 1230 帧中 1226 帧有效，完成 12 次推理，无异常重启；输出 `no_person`／`unknown`，真人坐姿准确率及长期稳定性仍待验收。配置、缩略图导出和验证边界见[运行说明](开发/摄像头实时坐姿检测运行说明.md)。

- **2026-10-30** 已启用 GPIO1、8 颗 WS2812 的低亮度绿色启动测试，构建、应用烧录校验和点灯驱动日志通过，用户确认“8 颗灯都亮绿色”，本次实物点灯验证通过。联调曾观察到摄像头取流后反复异常重启，当次关闭摄像头进行隔离，45 秒观察已连云且无异常重启；之后重新启用并修正摄像头接收，最新验证见上一项。接线见[灯圈说明](硬件/WS2812灯圈/参考例程说明.md)，详细验证见[运行记录](开发/开发板首次运行核对记录.md#2026-10-30-ws2812-灯圈上电测试)。
- **2026-10-30** 用户再次换网，现场确认设备因保存 Wi-Fi 而跳过 BLE，导致小程序添加页面无法发现。已备份并定向删除 Wi-Fi 配置，完整 NVS 回读一致，重启确认 BLE 配网启动成功；同日按用户要求再次清除新保存的 Wi-Fi，写入校验、完整配置回读及 BLE 启动验证通过。手机重新发现、新网络配网及连云仍待确认，详见[运行记录](开发/开发板首次运行核对记录.md#2026-10-30-再次换网与恢复设备发现)。
- **2026-10-30** 已接入震动模块并启用 GPIO5 启动时 500ms 单次脉冲；构建、应用烧录校验和设备控制调用日志通过，实际震感及带载供电仍待确认。接线与复测见[震动模块说明](硬件/震动马达/震动马达.md)，详细证据见[运行记录](开发/开发板首次运行核对记录.md)。
- 电脑端已完成工具链安装和构建；设备历史上已完成六镜像烧录、Wi-Fi 配网、普通复位自动连云及实际语音回答。连续追问的上下文承接、配网后断电冷启动与外设功能仍待验证。10 月 29 日摄像头启用固件已编译、烧录校验通过，接线复核后识别 BF3901（PID=0x3901）及初始化成功；当前观察到 Wi-Fi 断开，尚未验证连云后的取图。换网恢复曾确认重新进入 BLE 配网，手机重新发现、配网和绑定待确认，详见[运行记录](开发/开发板首次运行核对记录.md)。
- 赛题写作 `LJWB03`，手册写作 `XJWB03-DevKIT-V1`／`LJX40-Audio-KIT-V1`，配件照片丝印为 `LJWB76-DevKIT-V1`／`LJX40-Audio-Core-V1`。名称与硬件版本的对应关系待确认；来源参数不能覆盖实测记录。

## 🧭 组织与维护

- `meetings/` 放会议纪要、分工与待办，`创意/` 放候选想法，`赛事/` 放参赛安排与赛后资料，`赛题/` 放技术任务，`开发/` 放操作、平台协议和验证记录，`硬件/<模块>/` 放模块资料。当前无需再拆更多层级。
- 同一操作步骤集中在一份文档维护，其他文档链接引用；操作说明、历史验证记录和厂商资料各有用途，避免混写。其他型号参考资料通过官方资料索引查阅。
- PDF 文字、表格、代码转为 Markdown，默认不留 PDF 原件；实物、电路、接线、布局、方向及必要波形图放在当前文档目录的 `img/`，用相对路径引用，图注保留来源和原页码。WS2812 原始 ZIP 与解压例程继续保留。
- 未展开的源站附件只保留链接，不表示附件正文已归档；平台界面、装饰图片及视频未完整转录的范围见来源说明。
- 新增、合并或删除文档时同步修改索引与交叉引用；需求、选型及硬件参数未经核对时标为“待确认”。
