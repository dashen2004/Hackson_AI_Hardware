## 1. 概述

### 1.1开发板概述

分体华镇7014语音板，采用**华镇 VB7018F**语音芯片，需外接主控板使用，支持本地语音识别、实时语音交互与智能指令解析，可实现自然流畅的人机对话体验。

板载麦克风，标配PH2.0 喇叭接口，满足音频输入输出一体化需求；通信引脚通过排针外引，可外接主控板，便于外设扩展、二次开发与快速原型验证，适用于 AIoT、智能语音、WIFI 物联网等多场景应用开发。

### 1.2核心功能

| 项目 | 内容 |
| --- | --- |
| 语音交互 | 支持本地离线语音识别，可快速响应自定义语音指令，实现实时语音对话与智能语义理解 。 |
| 回声消除功能 | 内置AEC 回声消除算法，提升语音清晰度，适配复杂声学环境。 |

表1 核心功能表

### 1.3 硬件参数

| 项目 | 内容 |
| --- | --- |
| **语音芯片** | 高性能 32 位音频处理器，支持硬件浮点运算  内置 640KB SRAM  内置 Flash， VB7018F6（16Mb flash）/ VB7018F3（32Mb flash） |
| **工作电压** | TYPE-A供电工作电压：5V；外接主控板供电 |
| **麦克风** | **JMO-627B-423C-104P**驻极体麦克风（灵敏度≥-28dB，信噪比≥65dB） |
| **功能接口** | 1.引出通信引脚用于与主控板通信  2.TYPE-A供电与烧录调试接口  3.扬声器接口 |
| **工作温度** | -40~+85℃ |

表2 硬件参数表

### 1.4应用场景

**该设备的主要适用场景有：**

- 外接主控板二次开发
- 本地语音交互方案原型验证
- AIoT 产品方案前期可行性验证
