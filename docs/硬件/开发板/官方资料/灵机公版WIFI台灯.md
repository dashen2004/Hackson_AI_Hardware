灵机AI公版WIFI台灯 · 产品说明

使用LJB130-LED+HMI+Audio-KIT板，基于杰理 AC7911（AC7911B / WL82）的公版智能台灯产品应用。

产品通过 BLE 配网接入 Wi-Fi 与云端，支持**语音聊天**、**基础设置**与**灯光亮度 / 色温调节**：说出唤醒词即可与云端 AI 对话，触屏完成交互，暖 / 冷两路硬件 PWM 独立调光。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 语音聊天 | 本地唤醒词 → 云端 AI 会话，支持打断、退出、云端主动播报；唤醒后自动切到对话页 |
| 灯光控制 | 暖(PA09) / 冷(PA10) 两路硬件 PWM；亮度 8~100，色温 2700 / 3500 / 5500 K |
| 灯光模式 | 小夜灯 / 阅读 / 休闲 / 助眠，本地触摸与云端命令双向同步 |
| 基础设置 | 音量（拖动条 + 静音）、自动熄屏、语言、关于设备、重新配网 / 恢复出厂 |
| 配网与联网 | BLE 配网 + Wi-Fi + 动态注册 + MQTT 物模型；配网页实时反映重启 / 配网中 / 成功 |
| 触摸 UI | 12 个页面，触摸交互与页面切换 |
| 系统服务 | 按键（返回 / 唤醒）、电池检测、空闲自动熄屏与深度休眠 |
| 固件升级 | 网络 OTA（双备份，保留用户配置）；USB 独立烧录包 |

云端物模型对齐平台「公版 AI 台灯」（PID 11527）：siid=2 灯光、siid=4 音量、siid=6 语音控制。

## 硬件环境

### 构成一览

| 类别 | 型号 / 规格 | 说明 |
| --- | --- | --- |
| 主控 | 杰理 AC7911（AC7911B / WL82） | Wi-Fi + 双模蓝牙，整机主控 |
| 显示 | 2.4 寸 TFT，ST7789P3 驱动，240×320 | 屏幕模组 TFTST7789_2_4，SPI 接口 |
| 触摸 | CST836U 电容触摸 | 与显示配合完成页面交互 |
| 语音 | AC7911 内置语音链路 | 本地唤醒词 + 云端对话，不额外使用独立语音模块 |
| 灯光驱动 | U8 / U7 线性恒流驱动 | DIM 脚接 PWM，高电平点亮 |
| 调光 | 暖光 PA09 / 冷光 PA10 两路硬件 PWM | 亮度与色温独立调节 |
| 灯光参数 | 亮度 8~100；色温 2700 / 3500 / 5500 K | 对应小夜灯 / 阅读 / 休闲 / 助眠等模式 |
| 联网 | BLE 配网 + Wi-Fi + MQTT | 动态注册，对接云端物模型 PID 11527 |
| 调试串口 | UART1，921600 8N1 | USB CDC 已关闭，需 USB 转串口适配器接 DPA/DMA |

### 连接关系

AC7911（AC7911B / WL82）

├── SPI → 2.4 寸 TFT ST7789P3 显示（模组 TFTST7789_2_4）

├── 触摸 ← CST836U 电容触摸

├── 语音 ← 麦克风 / → 扬声器（内置语音链路）

├── PWM → 暖光 PA09 / 冷光 PA10 → U8/U7 恒流驱动 → 暖 / 冷灯珠

├── UART1 → 调试串口（921600 8N1，需 USB 转串口）

└── RF ↔ Wi-Fi / BLE → 云端（MQTT，物模型 PID 11527）

## 主控：杰理 AC7911

- **定位**：杰理 AC7911B（WL82），Wi-Fi + 双模蓝牙 SoC，作为台灯整机主控，运行 RTOS。
- **本方案使用到的能力**：
- 显示 —— SPI 驱动外接 2.4 寸 TFT（ST7789P3）；
- 触摸 —— 外接 CST836U 电容触摸 IC；
- 音频与语音 —— 本地唤醒词识别、语音上行 / 下行与提示音播放均由 AC7911 内置处理；
- 调光 —— 两路硬件 PWM（PA09 暖光 / PA10 冷光）驱动恒流回路；
- 联网 —— Wi-Fi 与 BLE 协议栈，用于配网与云端通信；
- 调试 —— UART1 串口日志（921600 8N1）。

## QUMIOS 说明

QUMIOS（QUMI 物联网组件层）是介于杰理 AC79 SDK 与台灯产品之间的可复用组件，把联网、配网、语音与音频等通用能力沉淀下来，产品侧只需实现台灯业务。

本方案使用的 QUMIOS 组件：

| 组件 | 作用 |
| --- | --- |
| qm_agent | 业务代理与任务调度，串起各模块运行 |
| qm_iot | 云端接入与设备物模型（MQTT），对齐平台 PID 11527 |
| qm_ble | BLE 配网，完成 Wi-Fi 凭据下发与配网状态反馈 |
| qm_audio / qm_player | 音频采集 / 播放与提示音，支撑语音链路与本地提示音 |

配网、联网、语音与音频链路均复用 QUMIOS，同一套逻辑可在不同板卡与产品间复用。
