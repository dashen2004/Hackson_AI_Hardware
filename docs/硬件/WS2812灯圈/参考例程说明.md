# WS2812 灯圈参考例程说明

> 来源：用户提供的 [WS2812灯圈.zip](WS2812灯圈.zip)。压缩包原件保留在本目录，内容已解压至 `参考例程/`，未修改源文件、未安装库或执行示例。

| 文件 | 内容 |

## 示例原有配置

| 配置 | 原示例内容 |
| --- | --- |
| 依赖库 | `Adafruit_NeoPixel.h` |
| 控制引脚 | `PIN = 6`，Arduino 示例引脚 |
| 灯珠数 | `NUMPIXELS = 16` |
| 数据格式 | `NEO_GRB + NEO_KHZ800` |
| 显示颜色 | `pixels.Color(0, 150, 0)`，绿色 |
| 单次延时 | `delayval = 500`，每更新一颗灯延时 500 ms |
| 行为 | 初始化灯圈后，循环依次设置灯珠为绿色，并调用 `pixels.show()` 更新；循环没有清空灯珠 |

原代码头部注明示例由 Shae Erisson 于 2013 年发布，采用 GPLv3，与 Adafruit NeoPixel 库许可匹配；后续使用需保留并核对第三方声明。

## 与项目接入相关的待确认项

- 原包下载链接指向 [FastLED](https://github.com/FastLED/FastLED/)，但 `.ino` 实际引用 `Adafruit_NeoPixel`。二者是不同库，不能将下载链接当作该示例的依赖声明。
- 开发板手册列出的 WS2812 配置为 GPIO1、默认 8 颗灯珠；此 Arduino 示例为引脚 6、16 颗灯珠。项目实际灯圈数量和引脚待确认，参见[开发板手册](../开发板/灵机XJWB03标准开发板使用文档.md)。
- 此示例未在 LJWB03 / XJWB03 开发板上编译、烧录或运行。具体供电方案、逻辑电平、SDK 适配和运行步骤待确认。
