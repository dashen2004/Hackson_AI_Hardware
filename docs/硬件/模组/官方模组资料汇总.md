## 语音模块

来源：[语音模块](https://xjiangiot.yuque.com/afahpl/qrhct7/urop5k0yh3mb7fhc)；原文内容更新时间：2026-10-21（UTC 日期）。

本文档为语音模块速览说明文档，汇总各型号语音模块的关键能力（通信方式、流控方案、音频格式、支持的语音功能、是否支持打断唤醒等），供选型与驱动开发速查。

### GX8006

| 项目 | 内容 |
| --- | --- |
| 通信方式 | UART ×3（全双工，最高 1.5 Mbps）；I²C ×1（主 / 从，100 kHz / 400 kHz / 最高 1 MHz，限 P2 & P3 且 VDDIO = 3 V）；I²S 输入 / 输出（主 / 从）；SPI 主 / 从；QSPI 主；PWM ×6；红外收发 |
| 流控方案 | 硬件引脚流控：UART2 支持流控，对应专用引脚 UART2_RTS / UART2_CTS（非协议约定） |
| 音频格式 | 数据手册未逐项列出编解码格式，仅说明「支持多种音频编解码」；ADC 采样率 16 kHz。MP3 / AAC / OPUS / PCM 等具体支持列表需向厂商确认 |
| 支持的语音功能 | 离线语音识别、关键词唤醒（keyword detection）、命令词识别；AI 降噪、波束成形（BF）、声源定位（DOA） |
| 是否支持打断唤醒 | 数据手册未明确标注。硬件具备 1+1 AEC（可边播放边采集），方案层是否支持语音打断需向厂商确认 |
| 官方资料链接 | <http://www.nationalchip.com> |
