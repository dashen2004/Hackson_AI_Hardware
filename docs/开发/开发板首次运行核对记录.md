## 音频实测与排查

- **已确认原因与处理**：麦克风与喇叭插头接反，用户纠正后确认有声音，后续联网对话确认正常语音回答。接线按语音板实际 `MIC` / `SPK` 标识核对，不能只按插头外形或模糊照片判断。
- **代码回退**：排查期间曾增加设备就绪等待、延长开机音超时，编译烧录后仍无声，因此已撤回。`qm_audio_device_vb701n.c` 和 `boot_sound.c` 恢复为当时 SDK HEAD 原始内容；回退后构建与应用烧录、哈希校验通过，应用大小恢复为 `0x2f8f70`（3,116,912 字节）。当时本机产品凭证与既有 `dev.bat` 修复保留，后者随后提交团队分支。
- **音频链路证据**：UART1，主控 TX=GPIO40、RX=GPIO39，波特率 2000000，流控输入 GPIO38；VB701N 返回版本 `1.1.7` 并持续返回麦克风 PCM。日志音量 80，对应芯片档位 24/31。这证明串口通信与音频上行工作，实际发声仍以用户听音为依据。
- **时序排查的范围**：原流程约 3.13 秒发送开机音、4.15 秒完成初始化；等待就绪方案曾触发原有 1 秒队列超时，进一步延长超时后队列超时消失，但用户仍听不到声音。该推测没有解决本次问题，不能写为已修复缺陷；这些调整不属于当前代码。
- **日志解释**：`local play done ret=-6` 对应 `-QM_ENOSYS`，当前 VB701N 适配层未声明物理播放完成确认（DRAIN）能力；该值不能单独证明 PCM 未发送或喇叭损坏。姿态推理使用内置 `bus.jpg`，也不能视作摄像头已取得实时图像。
