这个插件让 QUMI OS 设备可以通过语音或小程序播放云端音频。

它由 QUMI OS 的 Agent、云端消息、播放器、下载器、解码器和音频输出组件组成。本文只介绍 QUMI OS 组件和使用流程，不涉及产品应用代码。

## 第一部分：插件概述

### 1. 插件能做什么

- 播放、暂停、继续、停止云端音频。
- 播放音乐前先播放一段引导语。
- 通过 Agent 处理“下一首”和“上一首”。
- 让语音、TTS 和音乐共用 QUMI OS 的 `qm_audio` 音频输出。

### 2. 设备、小程序、云端链路

```text
@startuml
left to right direction

actor "用户" as USER
component "小程序" as APPLET

package "云端" {
    component "Agent 服务" as AGENT_CLOUD
    component "业务服务" as CLOUD
    component "MQTT" as MQTT
}

package "QUMI OS 设备" {
    component "麦克风" as MIC
    component "qm_agent" as AGENT
    component "qm_iot" as IOT
    component "qm_player_cloud" as PLAYER_CLOUD
    component "qm_player" as PLAYER
    component "qm_http" as HTTP
    component "音频解码器" as DECODER
    component "qm_audio" as AUDIO
    component "喇叭" as SPEAKER
}

USER --> MIC : 说“播放一首音乐”
MIC --> AGENT
AGENT --> AGENT_CLOUD : 语音请求
APPLET --> CLOUD : 选择歌曲
AGENT_CLOUD --> CLOUD
CLOUD --> MQTT : player 指令
MQTT --> IOT : device/down
IOT --> PLAYER_CLOUD : method=player
PLAYER_CLOUD --> PLAYER
PLAYER --> HTTP : 音频 URL
HTTP --> DECODER
DECODER --> AUDIO
AUDIO --> SPEAKER
PLAYER_CLOUD --> MQTT : playerReply / 播放状态
@enduml
```

语音控制和小程序点播都会在云端汇合，最后由 QUMI OS 的 `qm_player_cloud` 接收 `player` 指令。

### 3. QUMI OS 组件关系

```text
@startuml
top to bottom direction

component "qm_iot\n云端消息" as IOT
component "qm_agent\n语音与 TTS" as AGENT
component "qm_player_cloud\n播放器云控" as PLAYER_CLOUD
component "qm_player\n资源播放器" as PLAYER
component "qm_http\n网络下载" as HTTP
component "音频解码器" as DECODER
component "qm_audio\n共享音频输出" as AUDIO
component "喇叭" as SPEAKER

IOT --> PLAYER_CLOUD : player 下行
PLAYER_CLOUD --> PLAYER : 播放控制
PLAYER --> HTTP : 获取资源
HTTP --> DECODER : 音频数据
DECODER --> AUDIO
AGENT --> AUDIO : TTS / 语音回复
PLAYER --> AUDIO : 音乐
AUDIO --> SPEAKER
@enduml
```

### 4. 云端指令字段

| 字段 | 含义 |
| --- | --- |
| `method` | 固定为 `player` |
| `subMethod` | `play`、`pause`、`resume` 或 `stop` |
| `params.url` | 音频地址，播放时必填 |
| `params.audioType` | 音频格式，例如 `pcm` |
| `params.title` | 音频标题，可选 |
| `params.guideWords` | 播放前的引导语，可选 |

### 5. 常用语音控制

| 项目 | 内容 |
| --- | --- |
| 用户说 | QUMI OS 动作 |
| 播放一首音乐 | 接收 `player/play`，下载并播放音频 |
| 暂停 | 执行 `player/pause` |
| 继续 | 执行 `player/resume` |
| 停止 | 执行 `player/stop` |
| 下一首 / 上一首 | Agent 发送远程播放器控制 |

### 3. 常见问题

| 现象 | 优先检查 |
| --- | --- |
| 日志出现 `unhandled method=player` | `qm_player_cloud` 是否已注册 `player` 消息 |
| 收到指令但没有声音 | `qm_audio`、解码器和喇叭输出是否正常 |
| 有引导语但没有音乐 | 引导语结束后，`qm_player` 是否收到播放资源 |
| 播放马上结束 | 音频 URL 是否可访问，`audioType` 是否正确 |
