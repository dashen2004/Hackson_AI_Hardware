工作流是智能体处理复杂任务的核心能力，通过可视化画布把"判断、检索、调用、回复"串成流程，让智能体面对不同类型的问题时走不同的处理路径。

本文档回答四个问题：

1. 什么情况下需要工作流？
2. 工作流有哪些节点类型，分别做什么？
3. 如何编排一个"意图分发"工作流？
4. 如何调试、发布并关联到智能体？

完成本章后，你将能独立编排一个完整可用的工作流。

## 1. 工作流概念与适用场景

### 1.1. 工作流是什么

工作流是由多个节点组成的任务处理流程。每个节点负责一种处理动作（理解、检索、调用、回复），节点按顺序连接，形成完整的处理链路。

工作流解决的问题是：**智能体面对不同请求时，如何自动决定该怎么做**。

工作流是智能体的能力之一，与知识库、插件、垂类模型共同构成智能体的能力体系（关系说明见《智能体配置》第 4 节）。

### 1.2. 什么时候需要工作流

| 场景 | 说明 |
| --- | --- |
| 需要区分多种请求类型 | 用户可能闲聊、查天气、控制设备、问专业知识，需要分路处理 |
| 需要调用多个插件 | 不同请求调用不同插件，需要按意图路由 |
| 需要先检索再回答 | 先到知识库检索资料，再结合资料生成回答 |
| 需要多步处理 | 先理解用户意图，再执行操作，最后反馈结果 |
| 需要控制成本 | 闲聊用轻量模型，复杂任务用强模型，按分支差异化配置 |

如果产品只需要简单问答，可以不使用工作流，由智能体默认对话模型直接处理。

### 1.3. 工作流与智能体的关系

- 工作流在智能体配置页中挂载：启用开关控制是否生效，"高级编辑"进入编排器。
- 工作流随当前智能体草稿生成，**发布智能体时与智能体形成同步版本快照**，保证线上使用的工作流与发布时一致。

## 2. 工作流编辑器界面

工作流编辑器采用三栏布局：

| 区域 | 内容 |
| --- | --- |
| 左侧节点库 | 按类别分组的节点列表，可拖拽节点到画布 |
| 中央画布 | 工作流的可视化编辑区，节点连线形成流程 |
| 右侧配置面板 | 选中节点后显示该节点的参数配置 |

顶部工具栏提供：

| 工具 | 作用 |
| --- | --- |
| 自动保存 | 页面显示最近自动保存时间，编辑内容自动保存 |
| 执行调试 | 运行整个工作流，查看各节点的执行过程与结果 |
| 调试预览 | 以对话形式预览智能体执行工作流的效果 |
| 进入智能体 | 从编排器切换到智能体对话预览界面 |

画布支持缩放、适应画布等视图操作，流程较大时可缩放查看全貌。

## 3. 节点类型

### 3.1. 节点总览

| 节点类别 | 节点 | 作用 |
| --- | --- | --- |
| 流程控制 | 开始 | 工作流的起点，定义输入变量（文本、图片、文件） |
| 流程控制 | 结束 | 工作流的终点，输出最终结果 |
| 模型调用 | LLM | 调用大语言模型生成文本，可通过插件调用 MCP（原文注明：当前版本 MCP 暂未生效） |
| 模型调用 | 意图识别 | 调用大语言模型识别用户意图，用于路由分发 |
| 插件调用 | （插件名） | 调用已挂载的插件，如墨迹天气、作文批改、番茄时钟 |
| 知识检索 | 知识检索 | 从知识库检索相关文本片段 |
| 逻辑处理 | （逻辑节点） | 分支、循环、代码等控制逻辑 |

### 3.2. 开始与结束节点

- **开始节点**：定义工作流的输入，可选择文本、图片、文件等变量类型。用户对话内容默认作为工作流的输入。
- **结束节点**：定义工作流的输出，节点产出的内容（如回答文本）将作为工作流的最终结果返回给用户。

### 3.3. LLM 节点

LLM 节点调用大语言模型完成文本生成任务，用于回答、总结、改写等场景。

配置要点：

| 配置项 | 说明 |
| --- | --- |
| 模型 | 可单独指定模型；不指定时使用智能体的默认对话模型 |
| 提示词 | 定义该节点生成内容的要求，如"用亲切语气简要回答" |
| 输入 | 引用上游节点的输出作为输入 |

### 3.4. 意图识别节点

意图识别节点调用大语言模型判断用户的请求属于哪个意图，是"意图分发"型工作流的核心。

配置要点：

| 配置项 | 说明 |
| --- | --- |
| 模型 | 意图分类任务建议选择响应快的轻量模型，如 Doubao Seed 1.6 Flash |
| 提示词 | 说明各意图的定义和触发条件，以及未命中时的兜底行为 |
| 意图分支 | 配置多个意图分支，每个分支定义一条后续处理路径 |

### 3.5. 插件调用节点

插件调用节点在工作流中调用已挂载的插件。挂载到智能体的插件会自动出现在节点库的"插件调用"分类中。

配置要点：

- 选择要调用的插件（如墨迹天气）。
- 配置插件需要的入参（如查询的城市）。
- 引用上游节点输出作为入参，将插件返回结果传给下游节点。

### 3.6. 知识检索节点

知识检索节点从知识库中检索与问题相关的文本片段，用于"先检索、再回答"的流程。

配置要点：

- 指定检索的知识库范围。
- 设置检索的输入（用户问题或上游处理结果）。
- 检索结果可传给 LLM 节点作为参考内容。

### 3.7. 逻辑处理节点

逻辑处理节点用于流程控制，包括条件分支、循环、代码处理等，适用于需要复杂判断和数据处理的工作流。

## 4. 编排示例：意图分发工作流

下面以"艺境管家"智能体为例，演示如何编排一个意图分发工作流。该工作流把用户请求分为四类：闲聊、天气查询、作文批改、专注计时，分别路由到不同的处理分支。

### 4.1. 工作流结构

```text
开始
  └─ 意图识别（意图路由）
       ├─ 分支 0：闲聊       → LLM 节点 → 回答
       ├─ 分支 1：天气查询   → 墨迹天气插件 → 回答
       ├─ 分支 2：作文批改   → 作文批改插件 → 回答
       └─ 分支 3：专注计时   → 番茄时钟插件 → 回答
```

### 4.2. 编排步骤

自动生成：

当前版本自动生成系统预设的工作流和编排逻辑，手动编排可能会导致调试失败。

手动编排：

1. 添加开始节点：从节点库拖入"开始"节点，确认输入变量包含用户文本。
2. 添加意图识别节点：拖入"意图识别"节点，连接开始节点。
3. 配置意图识别节点：

    - 节点名称：意图路由。
    - 模型：选择响应快的轻量模型。
    - 提示词：说明各意图的触发条件，例如：

      > 请判断用户请求属于以下哪个意图：闲聊（不属于任何插件应用时触发，由 LLM 兜底回答）；天气查询（查询实时天气与未来预报、出行建议）；作文批改（学生作文批改与润色）；专注计时（番茄工作法计时与专注管理）。

    - 意图分支：创建意图 0（闲聊）、意图 1（天气查询）、意图 2（作文批改）、意图 3（专注计时）。

4. **添加各分支节点**：

    - 闲聊分支：添加 LLM 节点，配置提示词为"以亲切自然的语气与用户闲聊"。
    - 天气查询分支：添加"墨迹天气"插件节点，配置入参引用用户文本。
    - 作文批改分支：添加"作文批改"插件节点。
    - 专注计时分支：添加"番茄时钟"插件节点。

5. **连接回答节点**：每个分支末端添加"结束"节点（或回答节点），输出该分支的最终结果。
6. **保存并调试**：点击"执行调试"，验证各分支是否正确路由和执行。

### 4.3. 意图提示词编写要点

- 每个意图给出明确的触发条件，避免歧义。
- **必须包含兜底分支**（如"闲聊"或"其他"），保证未命中任何插件应用时，由 LLM 兜底回答，对话不中断。
- 意图数量不宜过多，建议控制在 5 个以内，过多会导致识别准确率下降。

## 5. 调试与发布

### 5.1. 执行调试

点击 **"执行调试"** 运行整个工作流，查看：

- 每个节点的执行状态（成功/失败）。
- 节点之间的数据流转。
- 最终输出结果。

调试时输入几条覆盖各分支的测试请求（如"你好""北京天气怎么样""帮我改一下这篇作文""帮我设一个 25 分钟专注"），确认每个分支都能正确路由和执行。

### 5.2. 调试预览

点击 **"调试预览"** 以对话形式与智能体交互，验证工作流在真实对话中的表现，包括调用时机、回复内容和回复速度。

### 5.3. 发布与版本同步

1. 调试确认无误后，返回智能体编辑页。
2. 确认工作流开关已启用。
3. 点击 **"发布新版本"**，工作流与智能体一起形成版本快照并生效。

**注意事项：**

- 移除智能体中的插件时，工作流中引用该插件的节点会失效，需要同步修改工作流。
- 修改工作流后，如果智能体已发布，需要重新发布新版本才会生效。

## 6. 完成标准与小结

| 任务 | 关键动作 | 完成标准 |
| --- | --- | --- |
| 确定使用场景 | 判断产品是否需要区分请求类型、串接多个能力 | 已明确工作流要解决的问题 |
| 设计工作流 | 画出处理路径：开始 → 意图识别/处理 → 分支 → 结束 | 流程覆盖全部请求类型，包含兜底分支 |
| 配置节点 | 配置意图提示词、模型、插件入参 | 各节点参数正确，插件入参引用无误 |
| 执行调试 | 用覆盖各分支的测试请求运行工作流 | 所有分支路由和执行正确 |
| 关联与发布 | 确认智能体工作流开关启用，发布新版本 | 线上智能体按新工作流执行 |

至此，智能体的四类能力（知识库、插件、垂类模型、工作流）配置完成。智能场景是平台能力而非智能体能力，用于"用一句话触发设备动作"，见第四章《平台能力》中的《智能场景》。
