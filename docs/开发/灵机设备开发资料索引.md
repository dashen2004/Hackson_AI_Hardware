## 适用性与整理范围

- XJWB03-DevKIT-V1 与 LJX40-Audio-KIT-V1 是当前项目已有使用记录的组合；4G、AC7911 台灯、杰理单麦板、双屏板及其他语音板作为官方参考资料，不表示本项目新增了这些设备。
- 板级参数按来源保留。XJWB03 页面中的 Wi-Fi 6 / 经典蓝牙条目与 ESP32-S3 不符；LJX40 页面的 VB7014F 与现有资料的 VB701N 命名、升级工具适配等存在差异，详见各页顶部说明。引脚位置、实物接线、未核对参数均待确认。
- 页面中的 QUMI / QUMIOS 路径、示例 PID、上游仓库与本项目实际环境可能不同。获取、构建和首次运行以[固件代码获取与运行说明](固件代码获取与运行说明.md)、[Windows 工具链安装记录](Windows工具链安装记录.md)和[开发板首次运行核对记录](开发板首次运行核对记录.md)为准。
- 本地保留文字、表格、代码和可解析的流程图；白板框图转为节点与连线文字。板卡外观、组件、接口和尺寸等必要图示保存到对应目录的 `img/` 并就近引用；平台界面截图、其他未保留图形和视频内容需从来源页面查看，不把未读取内容写成已知事实。
- PDF、ZIP、RAR、固件和工具附件：已有资料链接到本地 Markdown 或原有文件；其余只保留源站入口，未下载或展开，也未把附件正文视为已归档。本地不新增 PDF 原件，不执行来源页面的程序或操作。
- 本次为文档整理与引用检查；未修改固件、平台配置，未编译、烧录或进行实物验证。

## 官方通用上手流程与其他型号

官方[快速上手](https://xjiangiot.yuque.com/afahpl/qrhct7/iwp4g4gxafi7lyvw)（原文更新：2026-10-23，UTC）给出的通用流程为：选方案 → 准备对应开发板和 SDK → 平台建产品、取得 PID → 编译烧录 → 绑定 → 体验。本项目的操作细节统一见[开发板使用文档](../硬件/开发板/灵机XJWB03标准开发板使用文档.md)。

官方其他方案的区别：标准方案决定板型、仓库与平台信息；4G 设备使用二维码绑定，Wi-Fi 设备按小程序步骤绑定，并开启手机蓝牙和定位。平台入口为[灵机开放平台](https://platform.ljyd.cn)，另见官方[创建产品说明](https://xjiangiot.yuque.com/afahpl/qrhct7/tlq4vfmwt4rw5nt8)和[小程序指引](https://xjiangiot.yuque.com/afahpl/qrhct7/xvn5ff6vtwdqdcq2)。4G 等方案只作选型参考，不表示本项目已采用或验证。

其他型号的板卡、语音板与模组仍通过上表查阅；上游资料库自身的目录维护约定不作为本项目规则，项目文档组织以[文档索引](../README.md)和[协作指南](../../AGENTS.md)为准。
